# Open AgData logo

`open-agdata-logo.png` is the transparent horizontal logo used in the English and Chinese READMEs. The open circle represents access; field rows and a leaf represent agriculture; square pixels connect the mark to spatial data.

Generated with the built-in OpenAI image generation tool on 2026-10-15 and visually inspected for wording and composition. This is a raster PNG, not an editable vector. The asset is included under the repository's CC BY 4.0 content licence to the extent applicable.
